# World of Growth assets

The local 3D scene uses these Poly Haven assets. Poly Haven releases its HDRIs, textures, and models under CC0; attribution is not required, but the sources are recorded here.

License: [Poly Haven asset license](https://polyhaven.com/license) · [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)

| Asset | Scene use | Source |
| --- | --- | --- |
| `autumn_forest_03` | Environment lighting and distant forest backdrop (2K HDR) | [HDRI](https://polyhaven.com/a/autumn_forest_03) |
| `grass_ground` | Terrain base color, normal, and ARM maps (1K) | [Texture](https://polyhaven.com/a/grass_ground) |
| `forrest_ground_01` | Walking path base color, normal, and ARM maps (1K) | [Texture](https://polyhaven.com/a/forrest_ground_01) |
| `pachira_aquatica_01` | Growth tree and instanced woodland trees (1K glTF) | [Model](https://polyhaven.com/a/pachira_aquatica_01) |
| `shrub_02` | Instanced understory vegetation (1K glTF) | [Model](https://polyhaven.com/a/shrub_02) |
| `rock_moss_set_01` | Woodland rocks and obstacle markers (1K glTF) | [Model](https://polyhaven.com/a/rock_moss_set_01) |

Assets are served from `public/world/assets`, so the scene does not request models or textures from a third-party host at runtime. The bundled files total approximately 21.2 MB.
